# Simple Interest Calculator

This is a Bash script to calculate Simple Interest based on user inputs.

## 📘 Formula
Simple Interest = (Principal × Rate × Time) / 100
## 🛠️ How to Use

1. Clone the repository
2. Open a terminal in the project folder
3. Run the script:

```bash
./simple-interest.sh
Enter:

Principal amount

Interest rate (in %)

Time (in years)
